# Components

Core primitives cover buttons, inputs, cards, badges, alerts, tabs, progress, avatars, spinners, dividers, and layout. Data, learning, and reader primitives provide MetricCard, CourseCard, ProgressRing, Callout, and CodeBlock. Commerce is intentionally reserved for a later product phase; no payment flow is implemented here.

All components are presentational and do not own business logic, data fetching, routing, or payment behavior.
